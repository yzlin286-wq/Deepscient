# 示例 2：睡眠剥夺与工作记忆（被试内）

## 这是什么

22 名被试在两个条件下各测一次工作记忆容量：充分睡眠后、24 小时睡眠剥夺后。
同一批人测两次，所以是**配对**设计，不是两组比较。**示例数据，非真实实验。**

## 数据

`data.csv` 是宽表：

| 列 | 含义 |
| --- | --- |
| `subject` | 被试编号 |
| `well_rested` | 充分睡眠后的容量 |
| `sleep_deprived` | 剥夺后的容量 |

同一行是同一个人的两个条件。**行序不能乱**——配对检验靠行对齐，不是靠编号。

## 怎么跑

```json
{
  "testId": "ttest-rel",
  "csvPath": "data/exp1.csv",
  "columns": { "a": "well_rested", "b": "sleep_deprived" }
}
```

## 该看什么

1. 配对设计的正态性假设作用在**差值**上，不是两列各自。`assumptions` 里报的就是差值。
2. 效应量是 `cohens-dz`，与独立样本的 `cohens-d` 不能直接比大小——量纲不同，
   报告时要写明是哪一个。
3. 画图用 `paired` 类型：每人一条线，比两个柱状图信息量大得多，审稿人也更信。

## 一个常见的坑

把配对数据当独立样本跑 `ttest-welch`，会低估标准误、把 p 值做小。
如果你只想跑一个检验，先确认 `testId` 里的 `rel` / `paired` 是不是对的。
