# 新手上路：从装好到第一个课题

这份文件对应首次打开时自动弹出的六步引导。引导的进度存在本实例的数据根里
（`%USERPROFILE%\.deepscient\science\ui-settings.json` 的 `onboardingDone` / `onboardingStep`），
所以换浏览器会再出现一次，看到「跳过引导」也不会再烦你。想重来：设置 → 科研 → 重新打开使用引导。

## 一、先确认这套东西真的起来了

引导第一步读的是 `/deepscient/api/health`，三项都要对：

| 项 | 什么算对 |
| --- | --- |
| 产品 | `DeepScient` + 版本号，不是别的实例 |
| 科研库 | `available: true`；`source: runtime` 表示 dsh-science 正在运行，`package` 表示直接从包读（只读面板） |
| 数据根 | `%USERPROFILE%\.deepscient`（不是 `~/.dsh` —— 那是另一套实例） |

科研库没就绪时，工作台会直接告诉你缺什么，而不是显示一个空列表。

## 二、模型与 key 决定账记在谁头上

引导第二步列出当前默认模型与凭据来源（只显示掩码，例如 `sk-…4f2a`）。三件事要知道：

1. 默认模型由 `agentDefaultModel` 决定，换模型不影响已有会话，新会话才生效。
2. 一把 key 就是一个计费主体。用中转站时，实际扣费发生在**你的那把 key** 上，本页只做同口径统计。
3. 没配价目表也能看 token，只是不显示「≈金额」。价目在设置 → 计费价目里填。

细节见「计费与口径」这页。

## 三、文献 / 检索 API 可以先不填

八个数据源里，三个只要邮箱就能进 polite pool（OpenAlex、Unpaywall、Crossref），arXiv 免凭据。
全部留空也能跑，只是速率和元数据质量差一点。填写方式、验证方式、以及哪些字段当前版本的工具真的会读，
见「接入文献与检索 API」这页。

## 四、建课题

题目是唯一必填项。建完之后工作台会出现十二个阶段的进度条。学科和目标刊可以随时改，它们影响的是
默认假设、报告规范和目标刊模板，不是能力开关。

建课题会调 dsh-science 的 `createProject`，落在 `<数据根>/science/projects/<id>/` 下。
如果面板报 `root-mismatch`，说明两个进程的 `DSH_HOME` 不一致 —— 重启时别把 `DSH_HOME` 指到别处。

## 五、开一个会话，把下面任意一句粘进去

三段模板就是引导第五步给的三段，可以直接抄：

**选题定位**

```
我在做「<方向>」。请先用 science_frontier 扫一遍近两年的前沿锚点，
再用 science_topic_score 给三个候选选题打分，
最后只告诉我哪一个值得做成一篇、为什么。
```

**文献地图**

```
围绕「<研究问题>」建一张文献地图：核心 15 篇、方法线 5 条；
每条结论标出证据强度、是否可复现、以及它在原文里的出处。
```

**假设与样本量**

```
把「<现象>」写成可检验的假设：H1 明确自变量、因变量与预期方向；
用 science_exp_plan 给出最小可复现的样本量与实验步骤，并列出预注册要点。
```

会话必须在「科研模式」预设下开，否则工具不在手里 —— 本实例只有这一个预设，新会话默认就是它。

## 六、三条铁律

1. 每个结论都要能在原文里指出来；没有出处的断言算阻塞，不算「差不多」。
2. 数据、代码、图、环境指纹都留痕，重跑要能复现同一张图。
3. 阶段没过是门没开，不是模型偷懒：去工作台的「流程」看是哪一道门，它会告诉你补什么。

十二个阶段各有什么门、55 道门怎么判，看「十二阶段与门」这页。
