# 实验设计方法

## 适用场景
把研究假设转化为可执行、可预注册、可统计检验的实验方案。

## 步骤
1. 写出可证伪的研究假设，区分主要假设与探索性假设。
2. 定义自变量、因变量与控制变量，给出可测量的操作定义。
3. 设定对照组、随机化单位与盲法层级，说明具体实施方式。
4. 依据预期效应量与变异估算样本量，给出功效分析与敏感性范围。
5. 确定主要终点与次要终点，避免事后更换主要终点。
6. 规划数据采集流程、时间窗与质量控制点。
7. 列出失败判定、剔除标准与中途调整规则。
8. 完成伦理审批、知情同意与数据合规前置材料。
9. 在预注册中写明假设、设计与分析计划，标注偏离处理方式。
10. 输出实验方案、变量表与执行清单，交由复核人检查。

## 质量检查
- 方案中的每个指标都能被测量和复现。
- 样本量依据、伦理材料与分析计划相互一致。
