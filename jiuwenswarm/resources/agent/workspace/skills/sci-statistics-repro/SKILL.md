# 统计分析与可复现方法

## 适用场景
需要从原始数据得到可复核的统计结论，并保证他人能重跑分析时使用。

## 步骤
1. 建立数据字典，定义字段名、单位、取值范围与缺失编码。
2. 固定原始数据只读，所有清洗步骤写入脚本并记录变更日志。
3. 明确样本纳排、缺失值处理与异常值判定规则，避免按结果调整。
4. 依据研究设计与数据类型选择统计方法，先检查独立性、正态性与方差假设。
5. 报告效应量与置信区间，不只用 p 值表达结论。
6. 处理多重比较，说明校正方法与选择理由。
7. 做敏感性分析，验证结论对合理假设变化的稳健性。
8. 锁定依赖版本、随机种子与运行入口，保存环境文件。
9. 输出结果表、图形与复现说明，标注每一步对应的脚本。
10. 由第二人按复现说明独立运行，核对关键数字是否一致。

## 质量检查
- 结果可由公开脚本与声明数据重现。
- 统计方法、假设检查与解释边界写在同一处。
