# 投稿包准备方法

## 适用场景
论文定稿后需要选定期刊、准备投稿材料并应对审稿意见时使用。

## 步骤
1. 提炼研究问题、主要发现与创新点，形成三句话的投稿定位。
2. 按范围匹配、稿件类型、审稿周期、成本与可见度筛选候选期刊。
3. 比对目标期刊近期同类文章，确认选题与读者群契合。
4. 形成冲稳保三档投稿顺序，并记录每档的判断依据。
5. 撰写 cover letter：说明问题、发现、与期刊的契合点及原创性声明。
6. 整理作者贡献、利益冲突、伦理审批与数据可用性声明。
7. 核对格式、字数、图表数量与补充材料要求。
8. 收到审稿意见后逐条编号，分类为事实、方法、表达与补充实验。
9. 为每条意见写明回应、修改位置与证据，无法完成时说明理由与替代方案。
10. 汇总回应信与修改稿，做一次全文口径一致性检查。

## 质量检查
- 投稿材料之间的事实、数字与署名完全一致。
- 审稿回应覆盖全部意见，无遗漏条目。
